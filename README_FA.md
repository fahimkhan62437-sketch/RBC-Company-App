# راهنمای نصب RBC Company App نسخه ۲

## امکانات
- حساب مستقل مشتری: مجموع خرید، پرداخت و مانده حساب
- فاکتور چندقلمی با شماره قابل تنظیم
- دسته‌بندی و ثبت اجناس
- ثبت پرداخت‌های مشتری
- ساخت تصویر PNG با وضوح بالا و باز کردن منوی اشتراک‌گذاری اندروید
- پشتیبان‌گیری روزانه در پوشه `backups` و نگهداری ۱۵ نسخه آخر

## نصب در Termux
این پروژه را در پوشه جدید `RBC_Company_App_v2` قرار دهید. سپس:

```bash
pkg update
pkg install nodejs-lts
cd ~/RBC_Company_App_v2
npm install
npm start
```

در مرورگر گوشی باز کنید:
`http://127.0.0.1:3000`

برای توقف سرور در Termux کلیدهای `CTRL` و `C` را بزنید.

## نکات مهم
1. این نسخه پوشه قبلی `RBC_Company_App` را تغییر نمی‌دهد.
2. دیتابیس اصلی در `data/rbc.sqlite` ساخته می‌شود.
3. پشتیبان‌ها در `backups/` ذخیره می‌شوند.
4. پشتیبان خودکار زمانی اجرا می‌شود که سرور روشن باشد؛ برای اجرای روزانه، سرور باید حداقل یک بار در آن روز اجرا شود.
5. برای ارسال فاکتور، دکمه «نمایش / تصویر» را بزنید. تصویر PNG با وضوح ۲۴۸۰ پیکسل ساخته می‌شود؛ در گوشی از منوی اشتراک‌گذاری WhatsApp Business را انتخاب کنید. اگر منوی اشتراک‌گذاری فایل در دستگاه پشتیبانی نشود، تصویر در دانلودها ذخیره می‌شود و می‌توانید آن را دستی ارسال کنید.
6. قبل از استفاده واقعی، چند مشتری و فاکتور آزمایشی ثبت و خروجی/بازیابی پشتیبان را بررسی کنید.
7. این برنامه در این نسخه روی شبکه محلی گوشی اجرا می‌شود و ورود کاربری/رمزگذاری نسخه پشتیبان یا همگام‌سازی ابری ندارد؛ گوشی را قفل نگه دارید و فایل پشتیبان را در جای امن دیگری نیز کپی کنید.

## تغییر پیشوند و شماره فاکتور
از بخش «تنظیمات و پشتیبان» پیشوند و شماره بعدی را تغییر دهید. شماره‌های قبلی خودکار تغییر نمی‌کنند.
